# Frontend Engineering Journey

## Goal

Become a Senior Frontend Engineer by deeply understanding not only how things work, but why they work.
- JavaScript
- TypeScript
- Browser Internals
- React
- Next.js
- Git
- Docker
- Testing
- Performance
- Software Architecture

## 🛠 Learning Style

- Learn one concept at a time.
- Every session includes hands-on practice.
- Build a real project while learning.
- Create documentation after every session.
- Focus on understanding, not memorizing.
